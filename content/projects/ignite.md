## 게임 소개

지하 6층 연구 시설에서 깨어난 주인공이, 약할 때는 드론의 시야를 피해 숨고 힘이 차면 각성해 시설을 부수며 한 층씩 올라가는 3인칭 액션 게임

## 프로젝트 정보

- 팀 구성: 3인
- 게임잼: 에픽 메가잼 (2026 Epic AI MegaJam), 주제 "디렉터스 컷(감독판)"
- 개발 기간: 2026.11.12 ~ 2026.11.16 (5일)
- 담당: 레벨 디자인, 에셋 제작, 적(드론, 터렛) 제작 (AI 및 에셋)
- 출시: [itch.io](https://jokkilook.itch.io/ignite) (Windows)
- 개발 방식: Claude Code + Unreal MCP, 역할별 서브에이전트
- 사용 기술: Unreal Engine 5.8, C++, Blueprint

## 개요

잼 주제 "디렉터스 컷"을, 힘을 잘려 나간 주인공이 봉인을 부수며 잘린 능력을 되찾고, 각성할 때마다 맵에서 무엇을 부수고 남길지 플레이어가 직접 "편집"하는 구조로 풀었다.

숨어 있으면 안전하지만 계속 약하다. 드론 시야의 가장자리를 스칠수록 힘이 차오르고, 가득 차면 점화해 벽과 기계를 부수며 나아간다. 각성이 끝나면 다시 어둠이지만, 내가 부순 것은 그대로 남아 지름길이 되기도 하고 드론에게 훤히 보이는 빈틈이 되기도 한다. 봉인 장치를 부수면 구속구가 하나씩 풀리며 능력이 돌아온다.

## 역할

### 레벨 디자인

- 격리층부터 연구층, 드론 격납고, 동력층, 보안 검문층, 통제 사령부까지 지하 6층 구성
- 층마다 다른 올라가는 방법 (계단, 리프트, 각성 점프로 오르는 수직 공간), 적과 엄폐물 배치
- 게임 시작 장면: 격리실에서 깨어나는 오프닝 시네마틱

### 에셋 제작

- 시설 내부와 봉인 장치 등 레벨 에셋
- 파괴 연출: 드론·터렛 폭발, 콘크리트 덩어리·철판 파편
- 효과음

### 적 (드론, 터렛): AI와 에셋

- 드론과 4족 터렛의 행동: 시야 원뿔로 감지, 추격과 수색, 잠든 기체로 돌아가기, 드론 사격(3연사), 터렛 연쇄 폭발
- 드론·터렛 에셋과 애니메이션
- 최적화: 화면에 보일 때만 애니메이션 계산, 거리별 LOD (터렛 정점 약 65,000 → 최저 약 6,500)

## AI 활용 방식

- 팀원마다 자기 파트(기획 / 월드 / 플레이어 / 보스)를 맡아 각자 Claude Code 세션으로 작업하고, 브랜치를 합쳐 완성
- 기획서(GDD), 팀 공통 인터페이스 문서, 작업 규칙(`CLAUDE.md`)을 먼저 만들고, 기획·개발·QA·아트 역할별 서브에이전트를 정의해 작업을 나눔
- 개발 에이전트가 구현하고 리뷰 에이전트가 검토해 피드백을 주는 루프를 돌려, 결과물을 스스로 개선하게 함
- 자동 테스트(에디터 70여 개, 게임 월드 30여 개)와 맵 점검으로 변경을 확인하고, 손맛·난이도처럼 AI가 판단할 수 없는 것은 사람이 플레이해서 결정
- 실수한 것을 LESSONS 문서에 기록해 다음 세션이 반복하지 않게 함 (예: 빌드하지 않은 변경을 커밋해 빌드가 깨진 건, 같은 작업 폴더를 쓰는 세션끼리 git 인덱스가 섞인 건)
