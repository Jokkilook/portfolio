## 게임 소개

미스터리 방탈출 게임

## 프로젝트 정보

- 팀 구성: 3인 (상명대학교 게임전공 팀 프로젝트)
- 개발 기간: 2025.03 ~ 2025.07
- 담당: 기획과 아트를 제외한 개발 전반. 게임플레이 프로그래밍 (상호작용, 인벤토리, 세이브/설정, UI), 스팀 연동, 현지화
- 사용 기술: Unreal Engine 5, C++, Blueprint
- 출시: Steam

## 역할

### 상호작용 시스템 (C++)

- 카메라 라인 트레이스로 상호작용 대상을 감지하고, 인터페이스 기반으로 아이템 줍기, 자물쇠, 금고 등 여러 오브젝트의 상호작용을 같은 방식으로 처리
- 상호작용 대상에 아웃라인 표시, 상호작용 안내 위젯 구현
- 3자리 자물쇠 퍼즐: 게임마다 비밀번호를 무작위로 부여

### 인벤토리 & 아이템 살펴보기 (C++)

- 인벤토리 컴포넌트, 인벤토리 패널·슬롯·툴팁 UI 구현
- 아이템 데이터를 CSV/데이터 테이블로 관리
- 아이템 살펴보기: Scene Capture로 아이템 메쉬만 따로 렌더링하고, 메쉬 바운딩 박스와 카메라 FOV·거리로 스케일을 계산해 어떤 크기의 아이템이든 화면에 알맞게 보이도록 자동 조정

### 세이브 / 설정 시스템 (C++)

- 게임 인스턴스에서 세이브 슬롯 3개와 설정 파일을 관리. 플레이어 위치와 인벤토리 저장/불러오기
- 설정 화면: 언어, 마우스 민감도, 사운드 믹스 등

### UI & 연출

- 메인 메뉴, 일시정지 메뉴, HUD, 로딩 화면, 처음 조작 안내 UI (상호작용·인벤토리 키를 처음 쓸 때 안내 메시지 출력)
- 시네마틱, 기억 회상 연출 이미지

### 스팀 연동 & 현지화

- Online Subsystem Steam으로 스팀 도전과제 3종 구현
- 언어별 텍스트·폰트 설정, 번역 파일(.po)을 CSV로 변환하는 파이썬 프로그램을 만들어 현지화 작업에 활용

## 문제 해결

### 게임 시작 시 ESC, Tab 키가 먹히지 않던 문제

- 원인: 게임 속 노트북 위젯이 키보드 포커스를 계속 가져가고 있었음
- 해결: 노트북과 상호작용하는 동안에만 포커스를 가져가도록 변경

### 빌드 파일에서 언어 설정이 재시작하면 초기화되던 문제

- 해결: DefaultGame.ini에 설정을 추가해 선택한 언어가 유지되도록 수정

### 빌드에서만 마지막 메모 글씨가 보이지 않던 문제

- 원인: 위젯 컴포넌트의 무효화(Invalidation) 설정
- 해결: 무효화 사용 옵션을 해제해 해결
