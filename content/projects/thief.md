## 게임 소개

제한 시간에 최대 가치의 물건을 훔쳐야 하는 1인칭 도둑질 시뮬레이터

@video https://www.youtube.com/watch?v=NB9PaPo9BVo

## 프로젝트 정보

- 팀 구성: 2인
- 개발 기간: 3주 (2025.11.09 ~ 2025.11.30)
- 담당: 게임플레이 프로그래밍 전반 (캐릭터, 상호작용, 인벤토리, 아이템, 게임 흐름, UI), 레벨 디자인
- 사용 기술: Unreal Engine 5, C++, Blueprint

## 개요

제한 시간 안에 집 안의 물건을 훔쳐 가방에 담고 탈출하는 게임. 가방에는 무게 제한이 있어서, 어떤 물건을 담을지 고르는 것이 핵심이다. 시간이 다 되면 경찰이 출동하고, 제때 탈출하면 결과 화면에서 훔친 물건의 가치를 평가받는다.

## 역할

### 1인칭 캐릭터 & 상호작용 시스템 (C++)

- Enhanced Input 기반 이동, 달리기, 발소리 구현
- 카메라 정면 방향 라인 트레이스로 상호작용 대상을 감지하고, 인터페이스로 포커스/상호작용을 분리해 어떤 액터든 같은 방식으로 상호작용할 수 있게 구현

### 인벤토리 컴포넌트 (C++)

- 슬롯 개수와 무게 용량을 동시에 고려하는 인벤토리 컴포넌트 개발
- 겹칠 수 있는 아이템은 기존 스택을 먼저 채운 뒤 남은 수량을 빈 슬롯에 넣고, 무게가 초과되면 들어갈 수 있는 만큼만 추가
- 아이템 추가 결과를 성공 / 일부 추가 / 실패와 실패 사유(슬롯 초과, 무게 초과)로 나눠 구조체로 반환해 UI 메시지에 활용
- 델리게이트로 인벤토리가 바뀔 때마다 UI 갱신

### 인벤토리 UI

- 드래그 앤 드롭으로 슬롯 간 아이템 이동과 교체
- 우클릭 드래그로 스택을 절반으로 나누는 기능, 아이템 툴팁

### 아이템 & 게임 흐름

- 데이터 테이블로 아이템 데이터 관리
- 여러 스폰 영역 중 하나를 무작위로 골라 그 범위 안에 아이템을 랜덤 위치와 회전으로 스폰
- 제한 시간 타이머, 시간 초과 시 경찰 출동 시퀀스, 탈출 성공 시퀀스를 C++에서 레벨 시퀀스로 재생
- 결과 화면, 메인 메뉴, ESC 메뉴, 사운드 적용

### 레벨 디자인

- 게임 내 레벨 디자인 전체 담당

## 문제 해결

### 블루프린트에서 인벤토리 데이터를 못 가져오던 문제

- 증상: C++ 플레이어 클래스를 상속한 블루프린트에서 인벤토리 컴포넌트 참조가 끊겨 아이템 데이터를 가져오지 못함
- 원인: 블루프린트의 메타데이터가 깨지면서 컴포넌트 참조가 손상됨
- 해결: 블루프린트를 수정해 참조를 복구하고, 아이템 버리기 등 컴포넌트에 접근하는 코드에 null 체크를 추가해 같은 상황에서도 크래시가 나지 않게 처리. 같은 과정에서 아이템 가치가 무게에 더해지던 버그도 찾아 수정

### 다시 시작하면 의도와 다른 화면으로 가던 문제

- 원인: 다시 시작할 레벨 이름을 실행 중에 현재 레벨에서 가져오는 방식이 의도한 레벨 이름을 반환하지 않음
- 해결: 이동할 레벨 이름을 명시적으로 지정해 해결
