## 게임 소개

체력 바 없이, 공기총으로 상대를 밀쳐 아레나 밖으로 떨어뜨리는 1인칭 멀티플레이 링아웃 슈터

## 프로젝트 정보

- 팀 구성: 2인
- 개발 기간: 2026.10 ~ 2026.11
- 담당: 기획, 게임플레이 설계, AI 협업 개발, 스팀 출시
- 개발 방식: AI 도구(Claude Code)를 활용한 개발 (Unreal MCP, Blender MCP 연동)
- 사용 기술: Unreal Engine 5.8, C++, Blueprint, Steamworks
- 출시: Steam 얼리 액세스 (2026.11.09), 유료 ($6.99)

## 개요

총에 맞으면 체력이 줄어드는 대신 몸이 날아가고, 마지막으로 상대를 밀어 떨어뜨린 사람이 킬을 가져간다. 발밑을 쏘면 로켓 점프를 할 수 있고, 상대 발밑을 쏘면 더 높이 띄울 수 있으며, 상자를 쏴서 상대를 밀어낼 수도 있다.

## 주요 기능

- 게임 모드 5종: 개인전, 팀전, 크라운, 서바이벌, 펑 축구
- 아레나 6종 + 펑 축구 전용 경기장: 기울어지는 바닥의 용광로, 눈보라 치는 얼어붙은 호수, 움직이는 열차와 무중력 구역이 있는 궤도 정거장 등
- 스팀 온라인 멀티플레이 (방 만들기 / 방 코드로 참가), 로비
- 난이도를 고를 수 있는 봇으로 혼자 연습, 빈자리 채우기
- 튜토리얼 훈련장, 아이템, 연속 킬, 연장전, 경기 후 칭호와 하이라이트 리플레이
- 스킨 커스터마이징, 스팀 도전과제 50개, 32개 언어 지원

## 역할

기획, 설계 결정, 테스트·밸런싱, 출시 작업 등

## AI 활용 방식

아이디어를 제외하곤 모두 AI를 사용하여 제작하였습니다. 대신 AI가 틀리지 않고, 내 의도대로, 확인된 결과만 내놓도록 일하는 방식을 설계하는 데 집중했습니다.

### 역할 나누기

- **사람**: 무엇을 만들지, 제대로 되었는지, 재밌는지를 결정
- **AI (Claude Code)**: C++ 구현, 기획 문서 갱신, 에디터 에셋 작업, 3D 메시 생성 스크립트, 31개 언어 번역, 성능 측정

### 규칙 문서로 AI 다루기 (`CLAUDE.md`)

- 프로젝트 규칙을 문서로 정리해 모든 세션이 같은 기준으로 일하게 함: 코드 구조 원칙 (넉백·킬 판정·점수는 서버 권한, 무기 수치는 데이터 에셋에만), 손대지 말 것 (무기 수치 데이터), 커밋은 내가 말할 때만 하고 푸시는 금지
- AI가 빠졌던 함정을 규칙으로 쌓아 같은 실수를 막음. 예: 언리얼 유니티 빌드에서의 이름 충돌, Git LFS 병합 충돌로 깨진 에셋, 저장된 것처럼 보이지만 디스크에 안 남는 나이아가라 에셋

### 환각 막기

- 엔진 API와 콘솔 변수는 기억으로 쓰지 말고 엔진 소스에서 확인
- 에셋·맵 값은 짐작하지 말고 Unreal MCP로 읽어서 확인
- "됐다"는 빌드 결과, 파일 수정 시각, 로그 같은 증거가 있을 때만 보고하고, 직접 못 본 것 (플레이 느낌 등) 은 "확인 안 됨"으로 따로 적게 함
- 숫자는 직접 재거나 센 값만 쓰게 함

### 기획 문서를 단일 기준으로

- GDD (기획 문서) 를 살아있는 문서로 두고, 기능을 바꾸면 같은 커밋에서 문서도 갱신
- 결정을 하나하나 기록 (약 600건, 내가 직접 내린 결정은 따로 표시) → 세션이 바뀌어도 맥락이 이어짐

### 도구 연결

- **Unreal MCP**: 에셋, 맵, 위젯, 나이아가라 이펙트를 AI가 에디터에서 직접 다루고 결과를 다시 읽어 확인
- **Blender MCP**: 3D 메시를 파이썬 스크립트로 만들고, 스크립트를 원본으로 관리 (메시를 손으로 고치지 않음)
- **ElevenLabs**: 효과음 생성. 프롬프트를 문서로 남겨 같은 소리를 다시 만들 수 있게
- **전용 스킬 `/arena-review`**: 맵의 이음매, 틈, 뒷면이 빈 메시 등을 정해진 기준으로 찾아 보고하는 검토 절차를 만들어 재사용

### 검증 체계

- **자동 대전**: 봇끼리 매치를 반복시켜 CSV로 기록하고 밸런스 데이터를 모음. 실행기 GUI로 봇 수, 모드, 맵, 속도를 골라 여러 대전을 동시에 돌림
- **시험용 콘솔 명령**: 길찾기 점검, 기믹 시험 등 특정 상황을 바로 재현하는 명령을 만들어 AI와 내가 같은 방식으로 확인
- **성능 측정**: 패키징 빌드에서 CSV 프로파일링과 Unreal Insights 트레이스로 측정
- 손맛처럼 AI가 판단할 수 없는 것은 사람이 직접 테스트
