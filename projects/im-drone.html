역할

물리 기반 드론 비행 (C++)

  • 처음에 블루프린트로 만든 드론을 C++로 전환
  • 4개의 모터 컴포넌트가 각각 힘을 가하는 쿼드콥터 구조
  • PID 제어로 Yaw 회전 안정화, 뒤집혔을 때 처리, 최고 속도, 상승, 하강 속도 제한
  • 저사양 PC를 위한 단순화된 비행 방식(심플 모드) 추가

조작

  • 쓰로틀 AUTO / MANUAL 모드, 롤, 피치, 쓰로틀 민감도 설정
  • 게임패드와 드론 조종기(모드2) 입력, 화면 UI 컨트롤러 지원

게임 모드

  • 타임어택: 체크포인트, 다음 체크포인트 방향 표시, 타이머, 클리어 화면
  • 배달 모드: 패키지 픽업/투하, 충격 시 패키지 대미지, 비행기 함정
  • 보물찾기, 프리 모드, 미로 생성기, 무한 맵 생성
  • 비행 가능 구역을 벗어나면 글리치 화면 효과, 5초 안에 돌아오지 않으면 리스폰

레벨 디자인

  • 훈련장, 캐니언, 베니스, 지하철, 숲 등 여러 맵 제작. 지하철 맵에는 순회하는 열차, 숲 맵에는 동물 낙하 장애물 배치

UI & 설정

  • 메인 메뉴, 설정(그래픽, 사운드, 언어, 수직 동기화), 튜토리얼, 피치 확인 HUD
  • 비동기 맵 로딩, 기록 저장 시스템

현지화

  • 텍스트를 스트링 테이블로 관리하도록 전환하고 11개 언어 지원 (한국어, 영어, 중국어 간체, 번체, 일본어, 독일어, 프랑스어, 아랍어, 베트남어, 스페인어, 러시아어)

최적화

  • 나나이트 적용, 텍스처 크기 축소, 셰이더 최적화, 메인 메뉴 프레임 드랍 해결

문제 해결

C++ 전환 후 배포용 패키지가 실행되지 않던 문제

  • 원인: C++ 생성자에서 세이브 파일을 불러오는 함수(LoadFromSlot)를 호출하고 있었음
  • 해결: 세이브 로드를 생성자 밖으로 옮겨 해결

타임어택 시작 지점 통과음이 비정상적으로 크게 들리던 문제

  • 원인: 블루프린트 핀이 잘못 연결돼 시작 지점이 여러 개 겹쳐 생성되고, 그 수만큼 같은 소리가 동시에 재생됨
  • 해결: 연결을 바로잡아 시작 지점이 하나만 생성되도록 수정

속도 제한에 따라 조작감이 달라지던 문제

  • 원인: 쓰로틀 출력량이 속도 제한 값에 따라 바뀌는 구조
  • 해결: 쓰로틀 출력은 그대로 두고 속도 제한만 따로 적용하도록 방식 변경
